# Rule Editor — Demo

A visual editor for decision logic. Product Owners describe business rules,
AI agents use the exported JSON as implementation specs.

🔗 **[Try it online](https://visuellamende.github.io/rule_editor_demo/)**

## Features

- Visual decision tree editor with four node types
- Drag-free node creation (click "+" to build)
- Auto-layout for clean tree arrangement
- JSON & Markdown export for AI agents
- 4 color themes, 2 languages (DE/EN)
- Undo/Redo (Cmd+Z / Cmd+Shift+Z)

## Local Development

```bash
npm install
npm run dev
```

## About

This is the web demo of Rule Editor. The full desktop version (macOS)
includes file system integration, workspace management, and native dialogs.
